📊 Project Overview

This project analyzes 3,589 real military-to-civilian salary transitions to build a predictive model that helps service members understand expected civilian salary outcomes. The model achieves 96% accuracy using a Generalized Linear Model (GLM) trained with proper cross-validation.

Military rank dominates salary determination, explaining 95%+ of variance. This reflects direct salary-based rank correspondence and the alignment between military hierarchy and civilian career progression.

✨ Key Features

📈 High Accuracy

R² = 0.9627 on independent test set. Achieves 96% variance explanation with minimal overfitting.

🔍 Interpretable

Transparent GLM coefficients explain exactly which factors drive salary outcomes.

🔬 Model Insights

Feature Importance

The model reveals clear feature importance rankings:

  • Military Rank: 95.2% - Dominates salary determination
  • Years of Service: 3.1% - Secondary factor
  • Occupation: 1.4% - Minor contribution
  • Civilian Category: 0.2% - Minimal impact
  • Skill Level: 0.1% - Negligible contribution

Key Findings

  • Rank directly encodes compensation bands—higher ranks earn significantly more
  • Years of service has modest secondary effect on salary
  • Model is near-optimal; additional complexity provides minimal improvement
  • Skills feature explored but found redundant with occupation coding

📋 Data & Methodology

Data Source

3,589 real military-to-civilian transitions with complete records. Data quality: 0 duplicates, <1% missing.

Train/Test Split

  • Training: 2,512 records (70%)
  • Testing: 1,077 records (30% holdout)
  • Method: Stratified random split

Model Validation

  • Cross-Validation: 10-fold with R² = 0.8202 ± 0.0304 (conservative)
  • Test Set: R² = 0.9627 (96.27% variance explained)
  • Overfitting Check: 0.02% train→test drop (minimal)
  • Residual Analysis: Normally distributed, homoscedastic

Performance Metrics

  • RMSE: $5,003
  • MAE: $3,246
  • Prediction Range: $28,000 - $180,000
  • Mean Salary: $68,450

⚠️ Limitations & Disclaimer

This model is a powerful tool for understanding salary trends, but comes with important limitations:

  • Selection Bias: Only includes successful transitions; may overestimate for struggling separatees
  • Cross-Sectional: Snapshot in time; doesn't capture career progression
  • Missing Variables: Education, location/COL, benefits not included
  • Occupational Matching: ±3-5% error in niche specialties
  • Regional Variation: Ignores geographic salary differences (future enhancement)

Use responsibly: Combine with BLS data, career counseling, and personal judgment.
