## 📞 Need Help?

### Issue: Page not loading
→ Make sure you're using `python -m http.server 8000`
→ Don't use file:// protocol

### Issue: Styles look wrong
→ Hard refresh: Ctrl+Shift+R
→ Clear DevTools cache: F12 → Settings → Clear site data

### Issue: Image not showing
→ Check file exists: `Michael_9028-Bkgd-square.jpg`
→ Check filename is exact match (case-sensitive)

### Issue: Mobile layout broken
→ Use DevTools mobile view (F12 → mobile icon)
→ Don't just resize browser window
→ Test actual mobile device

### Issue: Links don't work
→ Verify file names and paths
→ Check relative paths from HTML location
→ Test locally first before deploying
