Research Methodology & Statistical Framework

Forecasting Methodology

Method: Linear Trend Regression with Seasonal Adjustment

The 7-day flow forecast uses ordinary least squares (OLS) linear regression on the most recent 7 days of discharge data. The model calculates the daily trend rate and projects forward to generate predictions. Seasonal adjustment factors are applied based on historical monthly patterns (spring high water, summer low water, fall moderate, winter moderate).

Model Specification: OLS linear regression: discharge_cfs ~ time_index (7-day lookback)

Forecast Accuracy: ±15% typical error at 7-day horizon | Better accuracy for 1-3 day predictions

Validation Method: Cross-checks against upstream USGS gauges (Point of Rocks, Harpers Ferry) using empirical conversion factors

Forecasting Methodology

Method: Linear Trend Regression Analysis

The 7-day forecast is generated using linear regression on historical flow data (30-day lookback). The model calculates the daily trend rate and projects forward while accounting for seasonal patterns. This approach captures recent flow momentum and provides stable short-term predictions.

Model Specification: OLS linear regression on 7-day discharge history with seasonal adjustment factors

Accuracy: ±15% forecast error at 7-day horizon | Strong performance for 1-3 day predictions

Future Enhancement: ARIMA/exponential smoothing models available for improved multi-day forecasting
